# P1-09 授权语义检索与证据组装

日期：2026-11-07。授权检索接口、证据上下文、引用复核与界面已实现；使用真实Milvus和受控嵌入夹具完成授权/恢复验收。**P1-08真实中文模型下载仍被当前运行实例的旧网络策略以403阻断，中文语义效果尚未验收**，不把夹具分数当作模型召回率或企业问答准确率。

## 当前可用边界

仅支持显式dense模式；不把hybrid/BM25悄悄降级成dense，不生成回答。默认配置仍关闭索引模型接入。没有可见已发布资料时返回真实空结果；有候选但模型/索引不可用时返回明确503，不伪装成“没有相关证据”。

新增迁移007为document增加 published_generation_id，并以外键绑定同租户、同文档、同原文版本的确切代际。不会替既有文档填写发布指针，也不会改变scan_status。旧记录即使有published_version_id，只要没有合法代际就不参与检索。

**当前上传仍保持草稿/待安全检查，产品尚无扫描与发布入口。** 集成测试在隔离schema中使用受信fixture设置clean及发布二元组；这不是对普通用户开放的发布接口。搜索参数无法指定任意版本/代际来绕过门禁。真实业务资料须等扫描/发布流程实现后才能进入检索。

## 三次门禁

1. **召回前（A）**：从服务端会话重新解析租户、成员、角色，计算KB/文档ACL交集。只选active文档/KB、clean原文、当前已发布版本/代际、ready且完整验证的索引；不从浏览器接收tenant、角色或过滤表达式。
2. **读取正文前（B）**：模型只接收用户问题，不接收候选正文。Milvus按服务端生成的tenant + generation + model_space限制召回；候选ID必须回到已授权的固定chunk产物，并有同代际、同文本摘要的PG收据。伪造向量元数据不能指向其他资源正文。
3. **组装前（C）**：S3读取后重新解析当前成员与资源权限、发布二元组、安全状态和收据，再返回snippet与context。文档/KB、原文和代际等必要共享锁持续到组装事务提交；检索期间撤权、换版、归档、删除或安全拒绝会移除相应证据。

PG一直是权限与发布真相源，active_hint和policy_bucket_ids不授予访问权。管理员没有跨资源ACL旁路。一次授权决策不能收回已发送到客户端的内容；后续生成、重排或Agent工具在发送上下文前仍必须复核来源，不能直接信任旧客户端snippet或模型自称的身份。

## 查询与预算

`POST /api/v1/search`，认证会话、Origin和CSRF；读操作不要求Idempotency-Key。字段白名单：

| 参数 | 规则 |
|---|---|
| query | 去首尾空白后1—1200 UTF-16字符 |
| kb_ids | 可省略，表示全部授权范围；显式指定时1—10个合法UUID，每个KB须有read权限 |
| top_k | 整数1—20，默认5 |
| mode | 只能dense，默认dense |
| min_score | 有限数值-1到1，默认0.25；是余弦排序阈值，不是可信度 |
| max_characters | 整数500—16000，默认6000；限制返回的规范context串 |

单次最多200个授权的已发布文档，超过返回422要求缩小范围，不静默忽略其他授权文档。每个代际召回最多 min(50,top_k×4)，最多4个并发查询；全局仅检查排名靠前的160个候选。请求有30秒协作式预算，单个在途Milvus调用还受其独立超时约束。读取产物按代际分组并顺序进行，只保留选中片段，避免把全部文档产物长期保存在内存。

按完整检索文本摘要去除授权候选中的重复证据，保留排名最高的确切来源。移除越权、失效或重复候选后，结果可能少于top_k；不以草稿、旧版本或其他模型空间补足。

`context`为逐行JSON对象组成的规范字符串，每段包含E1等局部证据号、标题、版本号、标题路径及完整excerpt。meta.context_characters严格等于context.length，含JSON转义和分隔符，整个片段超出预算则跳过，不截断表头/单元格或正文。该字符预算不等于模型token预算，系统提示、会话历史和后续工具内容仍需单独计算。

响应data包含稳定document/version/generation/chunk ID、原文version_no、rank/score、标题、snippet、章节、原结构span、短期citation_id和按当前download权限决定的原文URL。meta仅给本次返回数量、context用量、模式/原因与服务端请求ID，不返回隐藏资源总数、原始过滤表达式、collection、向量、对象key或凭据。全接口使用private/no-store并Vary Cookie/Authorization。

无证据时data=[]、context为空，reason区分无可见发布资料、无匹配证据或预算不足。某个PG就绪发布代际在向量库返回空候选时返回索引不完整错误，不把物理索引丢失当作普通空召回。

## 模型兼容与服务恢复

当前一次请求使用一个明确配置的模型空间。若授权发布范围中含其他空间，返回 SEARCH_MODEL_SPACE_UNAVAILABLE，要求协调模型路由与发布状态；不把旧维度的查询向量用于新集合，也不悄悄丢弃不兼容的可见资料。

发送查询给模型前先检查实际集合的维度和完整空间标识。检索请求不会创建collection或修改索引配置。Milvus暂不可用时明确失败，并避免浪费查询嵌入调用；恢复后需等待连接/索引就绪，可由维护者执行 `npm run index:warm` 预热当前已配置空间。预热不调用模型；物理向量缺失须通过P1-08的显式重建及发布流程恢复。当前验证形态仍是Milvus Lite，不构成Standalone/高可用验收。

## 引用复核

`GET /api/v1/citations/:citationId`：令牌HMAC签名，绑定租户、成员与确切文档/版本/代际/块，10分钟过期；不是匿名或永久访问凭据。每次重新鉴权并检查当前发布二元组、clean/active/ready状态与PG收据。换版、撤权、过期、篡改或换主体访问统一404，未登录401。

引用读取只返回重新核验的原文片段，rank/score为null，不伪造新的检索评分。下载URL仍须具备独立download权限，实际下载沿用现有动态授权。原文文件与引用都不会通过公共S3链接交付。
