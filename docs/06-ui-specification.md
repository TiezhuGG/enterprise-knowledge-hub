# 企业知识中枢：UI 信息架构与 32 屏设计规格

> 本文是界面设计任务书，不是已实现界面；本轮先完成计划与规格，再生成静态高保真 UI 画面；不编写业务应用代码。逐屏制作沿用固定 UI-01 至 UI-32，避免名称与编号漂移。所有演示数据必须虚构。

## 1. 设计方向与统一语言

目标用户使用中文桌面浏览器处理企业知识。风格以清楚、可靠、长时间阅读舒适为先：浅灰背景、白色内容层、深色正文、克制的蓝色操作色；产品可采用“企业知识中枢”作为工作名称。首版采用 React + TypeScript + Vite + Ant Design，实现应遵循本规格的产品规则，不能只照搬组件默认行为。

UI 不承诺“绝对正确”或显示缺乏校准的准确率百分比；以“有来源支持”“证据不足”“存在冲突”等事实状态表达。技术术语默认转换为可理解名称，例如“正在建立检索索引”，在高级详情中再提供分块、向量化等信息。

### 1.1 信息架构

```text
登录 → 工作空间选择
工作空间
├─ 总览
├─ 使用知识：智能问答 / 全局搜索 / 问答历史
├─ 管理知识：知识库 / 文档 / 导入任务 / 连接器与同步
├─ 提升质量：检索调试 / 评测集 / 评测对比 / 反馈整改
├─ 关系与自动化（P3）：图谱 / 实体 / Agent / 运行 / 审批
└─ 管理设置：成员 / 权限 / 模型 / 凭据 / 审计 / 运维 / 空间设置
```

仅显示当前角色有权使用的导航。普通员工无需理解存储、向量库或 Agent 框架；运营与管理员可以逐步展开高级信息。因权限隐藏的资源不出现在搜索建议、总数、最近访问或面包屑中。

### 1.2 桌面整体框架

```text
┌───────────────────────────────────────────────────────────────┐
│ 企业知识中枢  [工作空间 ▾]   [全局搜索 /]   任务  帮助  头像    │
├──────────────┬────────────────────────────────────────────────┤
│ 总览         │ 面包屑 / 页面标题              主要操作          │
│ 智能问答     │ 页面说明、筛选或范围                            │
│ 搜索 / 历史  │                                                │
│ 知识库       │ 主内容：表格 / 对话 / 编辑表单 / 分析             │
│ 质量与评测   │                                                │
│ 管理设置     │ 可选右侧：证据、属性、选中项详情                  │
├──────────────┴────────────────────────────────────────────────┤
│ 必要时展示连接中断、试点环境或数据更新滞后信息                   │
└───────────────────────────────────────────────────────────────┘
```

顶部高 72 px；侧栏宽 220 px，可收为图标栏；正文区最小舒适宽约 720 px；阅读列限制在约 760–880 px。设计以 1440 × 960 桌面画板为主，同时验证 1280 × 800，不依赖超宽屏才能完成任务。

## 2. 通用设计系统与状态合同

### 2.1 视觉与组件规则

| 维度 | 规格 |
|---|---|
| 字体 | 系统中文无衬线；正文 14–16 px，行高 1.5–1.7；长答案优先 16 px |
| 间距 | 使用 4 px 基础倍数，常用 8 / 12 / 16 / 24 / 32；相邻操作保持足够间距 |
| 色彩 | 主色 `#0A7D6B`；正文 `#173137`；背景 `#F5F7F9`；侧栏 `#102B30`；须用最终组件组合测对比度 |
| 状态 | 成功、警告、错误、处理中同时使用图标和文本，不能只靠绿黄红区分 |
| 控件 | 所有字段有常驻标签；必填标识加规则说明；禁用操作说明原因和可恢复路径 |
| 主操作 | 每个主要内容区域一个最突出操作；危险操作独立分组，避免与高频操作相邻 |
| 表格 | 固定表头、列宽可调；关键文本截断但可聚焦查看完整值；行菜单可键盘访问 |
| 表单 | 校验靠近字段；提交失败保留输入；退出未保存内容需提示；成功后显示具体结果 |
| 时间 | 默认展示用户工作空间时区，本项目演示用 Asia/Shanghai；跨日/到期时间显示日期与时区 |
| 通知 | 短暂 toast 只用于非关键结果；失败、审批、权限变化使用持久通知并可追踪 |
| 空白与文案 | 告诉用户当前是什么、能做什么；不使用“出错了”作为唯一说明 |

以上色值是设计初值，并非已通过可访问性验收的结论。实际设计需验证正文至少 4.5:1、大号文本及非文本关键控件至少 3:1 的目标，并用人工检查验证焦点和非颜色提示。

### 2.2 每屏必须落实的共同状态

- **空状态 E**：区分第一次使用、筛选无结果、没有获授资料；给出当前身份允许的下一步，不提示隐藏资源数量。
- **加载状态 L**：保留布局骨架；长任务显示服务端阶段、已完成项与可取消状态。禁止无限旋转且无解释。
- **错误状态 X**：显示可理解原因、是否可重试、错误关联 ID；不展示堆栈、内部地址、密钥或数据库详情。
- **无权状态 A**：页面直接访问显示统一“内容不可用或无权访问”；行级无权资源不渲染；操作级无权只在不会暴露资源时说明。
- **过期与冲突 S**：区别会话失效、数据版本已更新、权限变化和网络断开；保留安全可保留的表单输入，重新验证后重试。
- **成功状态 D**：明确完成了哪项操作；异步提交显示“任务已创建”，不能提前显示“全部导入成功”。

下面每屏的状态描述是在该共同合同之上补充具体情形；缺少某条补充不代表该屏可以省略 E/L/X/A/S/D。

### 2.3 响应式与无障碍

- 桌面 ≥ 1280 px：完整侧栏，支持主内容与证据双栏；1024–1279 px：收窄侧栏、证据改抽屉；768–1023 px：折叠侧栏，表单单列。
- 手机 < 768 px：阅读、搜索、问答、审批和基本任务查看可用；复杂图谱、编排、评测对比提供可读摘要及“请在桌面进行编辑”，不强迫用户横向拖动整个页面。
- 核心触控目标以 44 × 44 px 为设计目标；键盘焦点始终可见；Tab 顺序与阅读顺序一致；Esc 关闭非强制弹层并恢复焦点。
- 支持跳到主内容、语义标题、字段标签、表格说明；进度与错误以适当节奏向辅助技术播报，不能每个流式 token 都打断阅读。
- 问答发送可用 Enter，Shift + Enter 换行，输入框旁说明；中文输入法组合态不触发发送；提供按钮作为等价入口。
- 不把拖拽设为唯一上传、排序或编排方式；图谱提供实体与关系列表替代，颜色之外还有类型标签。
- 支持浏览器 200% 缩放、长中文标题、系统减少动画偏好；图标按钮有可读名称。

## 4. 逐屏规格

### UI-01 登录与身份校验

- **目标与布局**：组织标识、产品名、批准的身份登录入口、服务状态链接；演示环境可以出现演示账号入口并有显著标识。
- **字段与交互**：身份提供方名称、登录按钮、必要的错误提示；登录后返回安全的原目标页。回调目标需在允许范围。
- **权限与状态**：未登录可见；E 为尚未配置身份服务的维护提示；L 为跳转与校验；X 区分临时失败和无法登录并给关联 ID；A 为非组织成员的中性拒绝。离职账号不泄漏内部空间名称。
- **响应式与验收**：手机单列、焦点自动落到主要入口；重复点击不建立多次流程；会话过期返回后重新查权。

### UI-02 工作空间选择

- **目标与布局**：标题、当前账号、可访问空间卡片或列表、退出登录；P1 只有一个空间时可直接进入并保留切换入口。
- **字段与交互**：空间名称、角色摘要、最近访问；点击进入后清除前一空间检索缓存与界面状态。
- **权限与状态**：只列已获授空间；E 引导联系管理员，不展示其他空间；L 卡片骨架；X 提供重载；A 被移除后显示入口不可用。
- **响应式与验收**：桌面多列卡片、手机单列；切空间不能短暂闪出旧空间文档或历史。

### UI-03 工作空间总览

- **目标与布局**：欢迎区与提问入口；下方“可访问知识库、最近访问、我的任务”；运营增加“待审核、失败任务、过期资料”。
- **字段与交互**：数据时间、范围说明、任务状态；各指标点击进入带筛选的详情页，示例问题使用虚构或获授权内容。
- **权限与状态**：员工与运营布局按权限裁剪；E 给首个任务入口；L 各卡片独立加载；X 单卡片降级；A 移除受限卡片。计数仅统计当前用户有权看到的集合。
- **响应式与验收**：手机优先问答和待办；图表附数字或表格说明，不能依赖颜色理解待办严重程度。

### UI-04 智能问答

- **目标与布局**：左侧最近会话，中央问题与回答，底部固定输入区，右侧可展开证据栏；顶部清晰显示知识范围。
- **字段与交互**：问题、知识库范围、附件能力状态、发送/停止、重新生成、复制、反馈；答案包含结论、引用、冲突/不足提示和步骤摘要。
- **权限与状态**：E 用可访问库的示例问题；L 分“正在检索、整理证据、生成回答”；X 保留用户问题并区分重试代价；A 范围撤权后移除受限内容并中断受影响运行。普通日志不显示隐性思考。
- **响应式与验收**：手机隐藏会话侧栏，证据全屏抽屉；引用可键盘激活；中断保留已产生答案并标明“未完成”，不显示成完整成功。

```text
┌────────────┬─────────────────────────────────┬──────────────────────┐
│ 新建对话   │ 范围：已授权知识库 ▾            │ 引用证据             │
│ 最近会话   │ 用户：差旅需要哪些材料？        │ [1] 差旅制度 v3      │
│            │ 回答：……[1] ……[2]              │ 生效日期 / 页码      │
│            │ [有来源支持] [反馈]             │ 高亮原文与上下文     │
│            │ 可见步骤：检索 → 核验证据       │ 查看原文 / 版本状态  │
│            │ [输入问题……            发送]   │                      │
└────────────┴─────────────────────────────────┴──────────────────────┘
```

### UI-05 引用与证据核验

- **目标与布局**：答案中被引用的结论置顶；左侧文档预览与高亮，右侧来源元数据、版本状态与引用列表。
- **字段与交互**：文档标题、版本、生效时间、页码/段落、来源、负责人、生成时与当前状态；跳转相邻证据、查看上下文、获权时下载。
- **权限与状态**：每次打开再查权；E 无匹配证据则标明不可核验；L 预览骨架；X 预览失败可用经授权文本替代；A 只显示统一不可用消息，不保留旧标题。历史版本必须提示过期或已被替代。
- **响应式与验收**：窄屏上方预览、下方元数据；高亮可由键盘定位。复制的引用不包含长期有效的私密下载地址。

### UI-06 问答历史

- **目标与布局**：本人会话列表、日期与范围筛选、搜索、预览区域；默认按最近更新时间排序。
- **字段与交互**：会话标题、时间、知识范围、回答状态；重命名、继续提问、删除本人会话；批量删除需确认。
- **权限与状态**：默认仅本人；E 引导开始新问答；L 列表骨架；X 保留筛选；A 重新查权后隐藏不可显示内容。标题若含已撤权资料信息须脱敏为通用标题。
- **响应式与验收**：手机列表进入详情；历史引用按当前权限渲染，历史存在不授予原文阅读权。

### UI-07 全局知识搜索

- **目标与布局**：搜索框、知识库与文档类型/日期筛选、结果列表、可选预览；显式显示当前搜索范围。
- **字段与交互**：标题、授权片段、命中位置、版本有效性、更新时间；切换按相关性/时间排序，打开文档或带入问答。
- **权限与状态**：仅查询获授权的有效内容；E 区分无筛选结果与尚无资料；L 保留原结果并标示刷新；X 提供重试；A 结果消失后不解释隐藏资源。命中总数必须是授权后总数。
- **响应式与验收**：手机筛选抽屉、预览全屏；搜索建议和拼写提示也不能使用受限标题。

### UI-08 知识库列表

- **目标与布局**：标题、搜索/负责人/状态筛选、知识库表格或卡片、按权显示新建入口；选中库后可进入文档清单。
- **字段与交互**：名称、简介、负责人、可见文档数、更新时间、本人角色；查看、管理、归档按权限开放。
- **权限与状态**：仅显示已获授库；E 员工联系管理员、运营可新建；L 骨架；X 列表重载；A 被撤权库从列表移除。库内限制文档不计入读者可见数量。
- **响应式与验收**：手机卡片突出名称、负责人和访问入口；归档操作说明对检索的影响。

### UI-09 新建与配置知识库

- **目标与布局**：分步表单“基本信息 → 可见范围 → 处理与发布 → 确认”；编辑模式保留相同分组。
- **字段与交互**：名称、简介、所有者、授权组、发布审核、默认有效期、解析方案；提供最终配置摘要，创建后引导上传测试文件。
- **权限与状态**：管理员或被委派者；E 所有者/授权组未选时给就地提示；L 保存按钮忙碌；X 保留输入；A 失去管理权后只可安全退出。默认私有，不能因空权限表自动公开。
- **响应式与验收**：手机纵向步骤；表单更改有未保存提示；无法删除最后一位有效所有者。

### UI-10 文档详情

- **目标与布局**：标题与状态、原文预览、属性栏；“内容、元数据、相关任务”标签，运营增加处理与权限入口。
- **字段与交互**：来源、负责人、标签、有效期、当前版本、处理状态；搜索文内、查看引用位置、下载或申请访问（只对已知且允许申请资源开放）。
- **权限与状态**：读者看发布内容；E 文本为空显示解析问题；L 预览骨架；X 可授权查看原文件或重新解析；A 使用统一不可用页。无下载权时不提供可绕过的原文件地址。
- **响应式与验收**：手机属性折叠；长表格局部横向滚动而非整页；未发布版本不能从普通详情绕过审核。

### UI-11 上传与导入

- **目标与布局**：目标库、选择文件/拖入区、文件列表、发布前说明、提交与取消；批量元数据可展开。
- **字段与交互**：文件名、大小、格式、来源说明、负责人、有效期、权限继承；提交前逐文件校验，支持移除和重新选择。
- **权限与状态**：目标库运营；E 说明支持格式与当前上限；L 显示真实上传字节；X 逐文件错误不阻塞可用项；A 上传期间撤权则停止接受新文件并明确结果。敏感名称仅当前获权操作者可见。
- **响应式与验收**：手机支持文件选择，不依赖拖入；重复点击幂等；“提交成功”仅指任务创建。

### UI-12 解析与处理任务

- **目标与布局**：批次汇总、文件任务表格、选中任务的阶段时间线与日志摘要；支持失败筛选。
- **字段与交互**：阶段、已处理数量、耗时、重试次数、错误原因、任务 ID；重试失败项、取消、查看解析预览和分块位置。
- **权限与状态**：发起人及获授运营；E 暂无任务；L 阶段未知时展示活动状态不伪造百分比；X 显示可重试/需修改文件/需管理员介入；A 仅显示仍获权任务。混合批次有明确“部分成功”。
- **响应式与验收**：手机按文件卡片；刷新可恢复服务端进度；取消中与已取消是不同状态。

### UI-13 文档版本与发布

- **目标与布局**：版本时间线、当前发布标识、候选版本预览/差异、审核与发布操作区。
- **字段与交互**：版本号、上传者、审核者、变更说明、内容摘要、生效/失效时间；审核通过、退回、定时生效、撤回、从旧版创建新候选。
- **权限与状态**：资源运营及审核人；E 首个候选待处理；L 等待索引就绪；X 发布前置检查失败逐项提示；A 失去审核资格立即禁用动作。并发修改返回“已被其他人更新”，要求重读。
- **响应式与验收**：手机上下对比替代双栏；新版失败不使旧版下线；发布确认展示权限与有效期摘要。

### UI-14 数据连接器（P2）

- **目标与布局**：连接器列表与新建向导；配置分“来源、凭据、同步范围、权限映射、测试”。
- **字段与交互**：来源类型、允许地址/路径、凭据引用、计划、负责人、最近测试；测试只读连接、预览样本、启停。
- **权限与状态**：获授集成管理者；E 解释先接一个批准来源；L 测试连接；X 鉴权/网络/范围错误分别说明；A 无凭据使用权则不能绑定。展示凭据标识，不回显秘密值。
- **响应式与验收**：手机可查看与暂停，复杂映射建议桌面；未完成 ACL 映射不得自动发布。

### UI-15 同步任务与日志（P2）

- **目标与布局**：来源状态、运行列表、变更统计、选中运行详情和失败项。
- **字段与交互**：起止时间、上次成功时间、新增/更新/删除/撤权数量、游标状态摘要、错误关联 ID；手动同步、重试、暂停。
- **权限与状态**：目标来源管理者；E 尚未首次同步；L 分发现/拉取/处理/权限映射；X 显示部分失败且不宣称全量新鲜；A 按资源裁剪日志与统计。超时不显示为来源文件已删除。
- **响应式与验收**：手机优先上次成功时间和失败原因；看到数据滞后标识可直接定位负责人。

### UI-16 检索调试

- **目标与布局**：问题与授权范围、可选检索配置；下方并排展示稠密检索、关键词检索、融合/重排和最终证据。
- **字段与交互**：候选片段、位置、各阶段分数、截断原因、有效性；切换受控配置并比较，保存为评测样本。
- **权限与状态**：获授质量管理者，内容仍使用真实身份权限；E 未运行引导输入测试问题；L 分阶段展示；X 某检索分支失败明确降级；A 不提供“忽略权限”开关。分数不标成回答正确概率。
- **响应式与验收**：手机标签切换，桌面并排；能说明最终采用哪些证据、为何发生可公开的过滤，不展示隐性思考。

### UI-17 知识图谱（P3）

- **目标与布局**：实体搜索、类型与关系筛选、有限范围图形、图例、右侧证据和列表替代视图。
- **字段与交互**：节点名称、类型、关系名、证据状态；展开有限邻居、缩放、选中路径、打开实体详情。
- **权限与状态**：获授读者；E 当前范围无可用关系；L 按局部加载；X 图形失败时显示授权列表；A 过滤不可见节点、边与度数，不显示“隐藏节点”。未经审核关系需明显标识或不进入默认视图。
- **响应式与验收**：手机默认关系列表；键盘可搜索、选择实体与读取证据；不靠拖拽才能完成任务。

### UI-18 实体详情与纠错（P3）

- **目标与布局**：实体名称与类型、别名、关系表、来源证据、变更历史；运营显示纠错表单。
- **字段与交互**：规范名、业务标识、别名、来源版本、审核状态；提议合并/拆分/更名/关系纠正，审核后生效。
- **权限与状态**：读者只读、运营在资源范围纠错；E 无授权关系则只展示可见信息；L 各区域分载；X 冲突合并要求重新审阅；A 禁止通过合并预览泄漏受限实体。
- **响应式与验收**：手机按卡片；合并前显示可见影响与来源依据；不能把模型抽取置信分直接当成人工确认。

### UI-19 Agent 列表（P3）

- **目标与布局**：已批准 Agent 卡片、用途与允许动作、知识范围、状态、版本；管理者可进入编辑。
- **字段与交互**：名称、任务说明、读写类型、工具范围、发布者、预算摘要；启动、查看运行、复制为草稿。
- **权限与状态**：使用者只看可运行模板；E 提供获授模板说明；L 列表骨架；X 模板不可运行则给原因；A 未获工具或资源权时不可启动。草稿不会出现在普通用户列表。
- **响应式与验收**：手机卡片可启动只读任务；启动前能知道可能产生什么输出和哪些操作会需要审批。

### UI-20 Agent 编排（P3）

- **目标与布局**：模板节点列表或流程图、右侧配置、底部校验与试运行；基础流程为输入→检索→证据检查→生成→完成。
- **字段与交互**：节点类型、工具白名单、知识范围、超时、步数/费用限制、审批节点、版本说明；校验、保存草稿、试运行、发布。
- **权限与状态**：获授 Agent 管理者；E 从批准模板开始；L 保存或校验状态；X 显示未连接出口、缺少终止条件或未授权工具；A 权限变化阻止发布。无任意代码或任意 URL 执行节点。
- **响应式与验收**：手机只读流程与配置摘要；桌面提供非拖拽节点操作；发布前必须通过权限、终止和预算检查。

### UI-21 Agent 运行详情（P3）

- **目标与布局**：运行状态、输入与范围、可见步骤时间线、输出、工具结果摘要、资源消耗与关联审批。
- **字段与交互**：运行 ID、模板版本、步骤状态、开始/结束、允许公开的参数、结果引用；取消、查看失败原因、在重新查权后从模板再运行。
- **权限与状态**：发起人或获授运行管理员；E 待开始；L 运行中含心跳/更新时间；X 显示失败步骤和是否产生副作用；A 敏感步骤内容脱敏。隐藏思维链不进入时间线。
- **响应式与验收**：手机纵向时间线；刷新仍可恢复运行；暂停审批、超时和取消有独立终态说明。

### UI-22 审批中心（P3）

- **目标与布局**：“待我审批、我已处理、我的申请”标签；详情展示具体操作、目标、参数差异、理由和风险范围。
- **字段与交互**：申请人、Agent 版本、工具、目标对象、修改前后、有效期；批准一次、拒绝并填写原因，支持打开完整证据。
- **权限与状态**：指定审批人；E 无待办；L 载入最新参数；X 参数已变化或审批已过期需重新申请；A 当前不是审批人则不可见敏感详情。系统不以倒计时诱导批准。
- **响应式与验收**：手机可审批但必须看清操作摘要；重复批准只执行一次；批准后执行前重新查权。

### UI-23 评测集

- **目标与布局**：评测集列表、样本表格、类型分布、版本与冻结状态；创建/导入/校验入口。
- **字段与交互**：问题、期望证据、可接受答案要点、是否应拒答、难度、标签、标注者；编辑、抽样复核、冻结测试集、发起评测。
- **权限与状态**：获授质量管理者；E 用虚构样例解释标注方法；L 导入逐项校验；X 样本缺引用或无访问权时隔离；A 不复制无权原文。训练/调优集与独立验收集分开标识。
- **响应式与验收**：手机查看与单条复核，批量编辑桌面；冻结后更改生成新版本，不覆盖既有评测依据。

### UI-24 评测结果与方案对比

- **目标与布局**：评测运行选择、共同样本与配置摘要、质量/延迟/费用对比、逐问题差异和错误分类。
- **字段与交互**：样本量、Recall@K、引用支持、适当拒答、人工评分、P50/P95 延迟、用量；筛失败样本、查看证据、导出获授结果。
- **权限与状态**：获授质量管理者；E 未有可比运行；L 运行进度；X 缺样本、模型失败和部分结果分别显示；A 当前失权样本不展开。不同数据集或硬件对比须提示不可直接等同。
- **响应式与验收**：手机纵向方案卡和差异列表；不把单次提升写成统计上确定的提升；人工与自动评判分开。

### UI-25 用户反馈与整改

- **目标与布局**：员工看到本人反馈列表；运营看到授权范围队列、分类筛选、问题证据与处理记录。
- **字段与交互**：错误类型、问题、回答运行、来源版本、描述、负责人、状态；提交、分派、补充资料、修复后复测、关闭并说明。
- **权限与状态**：员工只看本人，运营只看资源范围；E 暂无反馈；L 提交/读取状态；X 失败保留输入；A 内容撤权后显示脱敏摘要。状态为新建→处理中→待复测→已解决/不采纳。
- **响应式与验收**：手机可从回答直接提交；关闭必须有处理结论，修复后可关联评测证明。

### UI-26 成员与组织

- **目标与布局**：成员、组、待邀请/待同步标签；表格与选中成员详情。
- **字段与交互**：显示名、稳定身份标识、组织组、角色、状态、最近登录；邀请或同步、禁用、转移资源所有权。
- **权限与状态**：成员管理员；E 无可管理成员；L 目录同步；X 身份冲突或禁用失败显示补救；A 无管理权限统一拒绝。禁用最后一位空间管理者需先完成转交。
- **响应式与验收**：手机查看与禁用确认可用，批量调整建议桌面；禁用后会话与新访问及时失效且有审计。

### UI-27 角色与资源权限

- **目标与布局**：角色能力矩阵、资源授权标签、用户有效权限预览；明确“继承”和“文档收紧”来源。
- **字段与交互**：主体、资源、允许操作、继承来源、有效期、授权者；新增/撤销、按用户核对权限、查看变更影响。
- **权限与状态**：权限管理员或获委派资源所有者；E 无额外文档限制时说明继承；L 计算授权预览；X 并发变化要求重读；A 委派者不能提升超过自身可授范围。影响预览不泄漏未获权资源。
- **响应式与验收**：手机用资源/主体列表代替宽矩阵；确认撤权后显示实际生效与异步清理状态，不能混为一谈。

### UI-28 模型与路由配置

- **目标与布局**：回答、向量化、重排模型分组；配置详情、测试区、预算与降级策略。
- **字段与交互**：供应方/部署位置、模型标识、凭据引用、上下文限制、超时、允许场景、预算；测试、保存候选、评测、切换生效版本。
- **权限与状态**：模型管理员；E 没有可用配置显示接入步骤；L 连通性与样例测试；X 超时/配额/不兼容明确分开；A 禁止读取无权凭据。模型能力以实际配置与测试为准。
- **响应式与验收**：手机查看与暂停，复杂编辑桌面；向量模型变化提示需要新索引，禁止悄然混用不同向量空间。

### UI-29 密钥与服务凭据

- **目标与布局**：凭据列表、用途与使用范围、轮换/撤销入口；新增通过受保护表单。
- **字段与交互**：别名、服务、创建人、到期日、最近使用、状态；输入新值、测试、轮换、撤销。保存后只显示掩码或不可逆标识。
- **权限与状态**：凭据管理员；E 尚无凭据；L 安全提交；X 测试失败不回显原值；A 不允许由接口或页面重新取回完整秘密。浏览器和通知不保存秘密值。
- **响应式与验收**：手机单列；撤销前展示当前有权看到的依赖与影响；剪贴板和页面录制不是默认传递机制。

### UI-30 审计日志

- **目标与布局**：时间、操作者、动作、资源类型、结果筛选；事件列表、详情与关联事件。
- **字段与交互**：发生时间、主体、动作、资源 ID、结果、关联运行、变更摘要；只读查询、获权导出、查看前后元数据。
- **权限与状态**：获授审计员和管理员；E 指定区间无事件；L 保留筛选；X 查询/导出失败独立提示；A 正文审计单独授权。普通审计事件不包含密钥、完整文档或隐性思考。
- **响应式与验收**：手机事件卡片；导出本身被审计，导出包内容不得超过当前授权范围。

### UI-31 运行监控与运维

- **目标与布局**：服务健康、处理队列、检索/问答延迟、模型错误、费用、容量与备份；详情按组件或时间展开。
- **字段与交互**：观测时间、告警状态、P50/P95、成功率、队列积压、上次恢复演练；确认告警、查看关联任务、执行获授运维操作。
- **权限与状态**：运维管理员；E 尚无监控样本；L 各面板独立加载；X 监控源断开显示“未知”而非“健康”；A 仅显示获授运行范围。日志敏感字段脱敏。
- **响应式与验收**：手机优先告警与关键健康；备份成功与恢复验证成功分开显示；模型不可用时员工端有一致降级提示。

### UI-32 工作空间设置

- **目标与布局**：基本信息、身份与登录、保留策略、功能开关、通知、导出与归档；危险操作置于独立区域。
- **字段与交互**：名称、时区、负责人、文件限制、会话/文档保留、批准的数据出口、增强功能状态；保存、查看影响、恢复已保存配置。
- **权限与状态**：空间管理员；E 未配置项有显式待完成；L 保存与验证；X 与现有任务冲突时解释生效时间；A 无权字段只读或隐藏。缩短保留期需展示具体清理计划并确认。
- **响应式与验收**：手机单列分组；参数变更生成配置版本与审计事件；P1 不呈现可点击但实际无功能的增强入口。

## 5. 关键路径与跨屏验收

| 路径 | 连接页面 | 必须覆盖的异常 |
|---|---|---|
| 首次获取可信答案 | 01 → 02 → 03 → 04 → 05 | 无授权资料、模型超时、无答案、冲突引用、生成中撤权 |
| 查找与核验原文 | 07 → 10 → 05 | 无结果、原文预览失败、引用版本已过期、下载无权 |

## 6. UI 画面制作与后续实现验收

1. **UI-D01 设计基线**：冻结信息架构、导航与设计 token；产出桌面和手机框架、组件清单、可访问性检查表。
2. **UI-D02 首条问答路径**：先画 UI-01–07；包含默认态、回答中、带引用回答、证据不足、冲突、权限变化六类场景。
3. **UI-D03 知识运营路径**：画 UI-08–13；逐步核验上传、部分失败、审核、版本切换与有效期信息是否连续。
4. **UI-D04 企业管理与质量**：画 UI-16、23–32；评测数据、权限范围、审计摘要需互相一致。
5. **UI-D05 增强路径**：画 UI-14–15、17–22；每幅明确 P2 或 P3 阶段，编排采用受控模板而非无限能力暗示。
6. **UI-D06 全屏状态补齐**：每屏记录默认、空、加载、失败、无权状态；高风险分支使用补充状态页与弹窗样式，实施时按逐屏规则展开。
7. **UI-D07 任务式走查**：用虚构“北辰制造”及“差旅制度 v3”等统一演示资料，分别以员工、运营、管理员、审计员完成关键路径。
8. **UI-D08 交付核验**：32 个 ID 无缺失且名称固定；链接关系、组件状态、文案、权限与阶段一致；验证桌面、窄屏、键盘和屏幕阅读顺序。

每屏至少一幅主态不等于完整 UI 交付。后续完整交付应包括 32 屏主态、必要异常态、组件状态说明和交互链接，并注明哪些为已验证设计、哪些仍待用户测试。
