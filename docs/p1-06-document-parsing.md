## 格式、结构与定位

| 首版格式 | 保留内容 | 定位与限制 |
|---|---|---|
| UTF-8 TXT | 段落、换行、中文和 Unicode | 原文件解码后 UTF-16 字符偏移 `[start,end)` 与1起始行号；BOM/CRLF计入偏移 |
| Markdown | 标题层级、标题路径、段落、列表项、代码、GFM表格 | AST 原文字符/行定位；表格第一行为显式表头；HTML仅作文字显示，图片发出未提取提示 |
| 文本型 PDF | 文字行、推断标题、重复页眉页脚、对齐表格候选 | 真实1起始页码，viewport scale=1 左上原点的 PDF point 坐标 `[x,y,width,height]`；表头未知时保存全部行，不猜测表头 |
| DOCX | 正文标题/段落/列表、表格、显式重复表头、合并标记、页眉页脚 | OOXML part、段落/表/行/单元格0起始索引；不伪造 Word 的物理页码 |

每个结构块包含稳定 ID、顺序、类型、标题上下文、文字和位置；单元格保留文字、位置和列跨度/纵向合并标记。标题上下文的导航标签最多200字符，正文完整保留并提示截断。此结构块尚不是检索 chunk。

DOCX 段落索引计入正文直接段落，表格位置单独计数；不能直接等同于 Word 编辑器的段落编号。自动列表编号、字段、文本框/内容控件、嵌套表格、图片、复杂修订和复杂版式不是完整 Word 渲染，检测到相应情况给出核验提示。删除修订不进入当前正文。PDF 采用位置启发式，所有 PDF 均标记版式/阅读顺序需核验；表格候选、旋转文字、多列、空白页另有提示。跨页表格不自动拼接。

全扫描/无可提取文字 PDF 返回 OCR_REQUIRED；部分空白页保留可提取内容并指出对应页需要 OCR。本阶段不执行 OCR，也不声称已识别图片文字。加密 PDF 要求移除密码，损坏文件要求重新导出；宏、危险 XML、过度 ZIP 展开、乱码或资源超限均提供明确原因。仅接受规范的 ZIP 型 DOCX；旧版 DOC、Office OLE 加密容器及其他格式需转换后上传。

## 存储、权限与恢复

原文件按固定 S3 VersionId 读取并核对 SHA-256。结构全文作为有大小上限的 JSON 保存到私有版本化 S3，PG 保存版本/源摘要/解析器版本、产物摘要及稳定块 ID、位置、标题路径、文字摘要和长度。输出表拒绝 UPDATE。浏览器不会获得 S3 key、版本号或凭据。

`GET /api/v1/documents/:documentId/versions/:versionId/parsed?limit=10&cursor=...&page=2` 返回授权后的结构预览。page仅适用于PDF；签名游标绑定当前成员/授权版本、文档版本、过滤和页大小。每次访问复核当前成员与文档/版本可见性；草稿仍仅向编辑/发布/管理者开放。未知/无权资源统一404，无结果409；原文件下载沿用独立 download 权限。

Worker 在读取、解析提交前后复核执行权限、源安全状态、截止时间和租约。取消或旧租约的晚到结果不能建立产物记录、检查点或改变终态。产物使用内容摘要命名，相同重试可复用固定对象；事务提交前后崩溃仍由租约恢复。不修改 latest/published 指针，scan_status保持 pending。S3写入后、PG提交前中断可能留下未引用的派生产物；当前上传清理器不清理 parsed 前缀，生产需增加基于引用和保留期的回收，不能直接对该前缀设置过期删除。

## 隔离与资源预算

解析运行在独立 Node 子进程；不继承数据库、S3或会话凭据，不执行 PDF JavaScript、Word宏或Markdown HTML，不主动访问文档外链。Node权限模型限制文件读取到代码依赖，禁止写盘/子进程/Worker线程并禁用字符串代码生成；允许 PDF.js 所需的受信原生依赖。父进程可取消/超时杀死子进程，子进程检查父PID。Linux安装 prlimit 时增加CPU时间上限。

这是进程与 Node 权限隔离，**不等于操作系统级恶意文件沙箱**。V8堆上限不涵盖全部原生内存，Node权限模型/原生插件也不是完整安全边界；生产应在无出站网络、有总内存/CPU限制的专用容器中运行，并接入独立恶意文件扫描。文件不会因解析成功被标为安全。

| 配置 | 默认值 |
|---|---:|
| PARSER_MAX_BYTES | 10 MiB |
| PARSER_MAX_CHARACTERS | 1,000,000 |
| PARSER_MAX_BLOCKS | 10,000 |
| PARSER_MAX_PAGES | 200 |
| PARSER_MAX_OUTPUT_BYTES | 5 MiB |
| PARSER_TIMEOUT_MS | 30,000 |
| PARSER_HEAP_MB | 256 |
| PARSER_MAX_ZIP_BYTES | 20 MiB（所有条目声明展开大小之和） |
| PARSER_MAX_ZIP_ENTRIES | 1,000 |

ZIP另限制大条目压缩比。整体执行预算仍受 INGEST_DEADLINE_MS 约束。超时/资源不足/启动失败可人工重试；加密、损坏、扫描件和格式问题需处理原文后上传新版本，不自动反复解析。
