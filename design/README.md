## 使用说明

PDF 为可缩放矢量设计，逐屏 PNG 为1440×960。普通员工页面精简管理导航，知识运营和管理员按委派能力展示。UI-13 展示发布前的版本审核，UI-04/05 展示发布后的问答与引用，二者是同一业务链的不同状态。

各页空、加载、错误、无权和冲突规则见 docs/06-ui-specification.md；补充页提供共用视觉方案。静态稿无法验证键盘、读屏或实际网络行为，这些在实施阶段按规格验收。
